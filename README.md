# 💜 Birthday Countdown — For Likky Vadhina

A simple, elegant and aesthetic birthday countdown website created specially for **Likky Vadhina**. ✨

The website counts down to **18 October 2026** and reveals a special birthday message when the countdown reaches zero. 🎂💜

## ✨ Features

* ⏳ Live birthday countdown
* 📅 Countdown to **18 October 2026**
* 💜 Lavender-based aesthetic theme
* ✨ Soft glow and smooth animations
* 📱 Fully responsive design
* 🎂 Automatic birthday reveal
* 🎀 Simple and minimal UI
* 🖼️ No photos required

## 🎨 Theme

The website uses a soft **lavender and purple** color palette to create a dreamy and elegant birthday atmosphere.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. The countdown will start automatically.

## ⏰ Countdown Target

**Date:** 18 October 2026
**Time:** 12:00 AM

When the countdown reaches zero, the website automatically displays:

> 🎉 HAPPY BIRTHDAY LIKKY VADHINA 🎂
